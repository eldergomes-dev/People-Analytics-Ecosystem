# 🚀 People-Analytics-Ecosystem

Bem-vindo ao **People-Analytics-Ecosystem**! Este repositório centraliza uma arquitetura integrada de soluções tecnológicas, automação de processos corporativos, inteligência de dados e engenharia de software — totalmente focada na resolução de problemas reais de **Recursos Humanos, Gestão de Pessoas e Analytics**.

---

## 📁 Estrutura do Ecossistema

O repositório é organizado de forma modular e temática, dividindo cada tecnologia pelo seu verdadeiro propósito no mercado de trabalho:

* **`01_Analise_e_Dados/`**
  * **Power BI:** Dashboards corporativos, medidas DAX e modelagem de People Analytics.
  * **SQL (MySQL):** Consultas relacionais, extração e manipulação de bases de dados de RH.

* **`02_Automacao_e_Workspace/`**
  * **Python:** Scripts de tratamento automatizado de dados, relatórios e rotinas de backend.
  * **Google Apps Script:** Integração e automação nativa do Google Workspace (Sheets, Forms, Docs, Gmail).

* **`03_Sistemas_e_Backend/`**
  * **C# / Java / PHP:** Regras de negócio, serviços corporativos e desenvolvimento de aplicações backend para RH.

* **`04_Portais_e_Frontend/`**
  * **HTML5 / CSS3 / JavaScript:** Interfaces web, portais do colaborador e formulários interativos de recrutamento.

* **`05_Engenharia_e_Logica/`**
  * **C / C++ / Assembly (NASM):** Fundamentos de lógica, gerenciamento de memória e algoritmos de alta performance.

* **`06_Scripting_e_Terminal/`**
  * **PowerShell / Windows CMD:** Scripts em lote, automação de infraestrutura e gestão de arquivos locais.
