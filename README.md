# 🚀 People-Analytics-Ecosystem

Bem-vindo ao **People-Analytics-Ecosystem**! Este repositório centraliza uma arquitetura profissional de **Análise de Dados e Engenharia para RH**, focada em transformar dados brutos de Gestão de Pessoas em decisões estratégicas através de um pipeline completo e integrado.

---

## 🎯 Metodologia dos Projetos (Pipeline de Dados)

Todos os projetos deste ecossistema (localizados na pasta `01_Analise_e_Dados/`) seguem um **padrão rigoroso de engenharia de dados**, integrando 5 etapas fundamentais:

1. **🛢️ Banco de Dados (SQL):** Modelagem de dados relacionais e extração de métricas brutas no MySQL (`.sql`).
2. **🐍 Automação & ETL (Python):** Scripts automatizados para extração, limpeza, tratamento e regras de negócio (`.py`).
3. **📊 Output Tratado (CSV):** Geração do dataset limpo e padronizado pronto para consumo (`.csv`).
4. **📋 Integração Corporativa (Excel/Sheets):** Espelhamento e relatórios operacionais em planilhas (`.xlsx`).
5. **📈 BI Executivo (Power BI):** Dashboards interativos e medidas DAX para decisão estratégica (`.pbix`).
